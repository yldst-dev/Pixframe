# Pixframe Skills

This directory contains a curated set of agent skills vendored into this repo for offline/local use.

## Included Skills

- `skills/frontend-design` (Anthropic)
- `skills/webapp-testing` (Anthropic)
- `skills/theme-factory` (Anthropic)
- `skills/frontend-dev-guidelines` (Antigravity)
- `skills/error-debugging-error-analysis` (Antigravity)
- `skills/ui-ux-pro-max` (nextlevelbuilder)
- `skills/vibesec` (BehiSecc)

## Not Included

The following repo has useful content, but the skill packs are currently only available in zh-CN / zh-TW, so they are not vendored by default:

- https://github.com/affaan-m/everything-claude-code
